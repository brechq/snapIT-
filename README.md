# snapIT! 📸

A free, lightweight, client-side Neo-Brutalist online photo booth web application.

- **100% Client-Side:** No backend, no login, no database, no watermark, no tracking.
- **Neo-Brutalism Design:** Hard offset shadows, thick borders, high-contrast flat colors.
- **16 Diverse Layouts:** 1 to 8 photo strips, grids, collages, polaroid, 35mm film format.
- **Interactive Stickers & Doodles:** Drag-and-drop, resize, and delete 14 vector stickers on your photos.
- **Camera & Instant Export:** Mirror selfie preview, camera switch (front/rear), countdown timer, live filters, and print-quality PNG download.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via any static web server:

```bash
# Using Python
python -m http.server 8080

# Or using Node
npx serve
```

## 🛠️ Built With

- Pure Vanilla HTML5, CSS3, and JavaScript
- Zero external libraries or frameworks
- Native MediaDevices and Canvas APIs
